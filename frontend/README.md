# Frontend - Expense & Reimbursement Agent

Angular 21 app (standalone components, signals, zoneless). See the [root README](../README.md) for the full setup.

```bash
npm install
npm start        # dev server on http://localhost:5200
npm run build    # production build in dist/
```

The API URL and UI options are read at runtime from `public/config/app-config.json`.
